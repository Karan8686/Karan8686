### 👨‍💻 About Me

- 📱 **Mobile & Software Engineer** with a strong focus on building responsive, high-performance apps using **Flutter & Dart**.
- 🪨 Creator of [**`caveman-plus`**](https://github.com/Karan8686/caveman-plus) — a lightweight, zero-dependency programmatic text compression engine for LLMs and AI workflows that cuts 40–70% of tokens while preserving technical accuracy.
- 📦 Open-source contributor building modular mobile packages like [**`adaptive_image_loader`**](https://github.com/Karan8686/adaptive_image_loader) and [**`adaptive_image_picker`**](https://github.com/Karan8686/adaptive_image_picker).
- 🎯 Passionate about clean architecture, reactive state management, seamless animations, and developer tooling.
- 💬 Let's talk about **Flutter, Dart, Mobile Architecture, TypeScript, or AI Integration**.
